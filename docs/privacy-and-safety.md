# Privacy And Safety

Public demos must use synthetic submissions, synthetic rubrics, fake course
identifiers, and public-safe sample outputs.

Do not publish:

- real student submissions
- real student names, emails, IDs, grades, or comments
- Canvas user, course, assignment, or submission IDs
- API tokens, OAuth files, or credential JSON
- teacher-only review artifacts from a real class
- private screenshots or LMS exports

## Public Demo Rule

Every committed example should be inspectable without access to a private LMS,
private course, private student record, or private institutional context.
